Experiència VR al navegador

Un shooter FPS de primera persona construït a UE5, adaptat per jugar directament al navegador sense instal·lació addicional.

01 — Sobre el projecte

Tecnologia & Arquitectura

🎮
Unreal Engine 5.5.4

Motor original del joc. Exportat a WebGL/HTML5 mitjançant plugin comunitari. Lluminació estàtica (baked), sense Lumen ni Nanite per compatibilitat web.

🌐
Frontend Web

HTML5, CSS3 i JavaScript vanilla. El joc es descarrega i executa a la GPU/RAM de l'usuari. Sense límit de jugadors simultanis.

⚙️
Backend PHP 5

API REST lleugera amb PHP 5 clàssic. Consultes preparades (PDO) per evitar injeccions SQL. Base de dades MySQL per a puntuacions.

📡
Temps real

La taula de classificació es refresca automàticament via polling AJAX. El joc envia la puntuació final a través d'una crida JSON a la API.

🎯
Controls FPS

WASD per moure's, ratolí per apuntar, clic esquerre per disparar. L'API Pointer Lock del navegador captura el cursor dins del joc.

🔒
Seguretat

Totes les peticions a la API validen el token de sessió. Les puntuacions s'envien en POST xifrat per evitar manipulació des del client.

02 — Pla d'acció

Roadmap · 3 Setmanes

S1Setmana
1

🔴 Decisió crítica — Test d'exportació

Instal·lar el plugin comunitari HTML5/WebGL per a UE5 i exportar una escena mínima (un cub en moviment). Si l'exportació falla de forma irrecuperable → migrar a Unity o Godot.

  • Instal·lar plugin ue4-web-runtime o equivalent UE5
  • Desactivar Lumen, Nanite i il·luminació dinàmica
  • Provar en Chrome, Firefox i Edge
  • Mesurar temps de càrrega i ús de memòria
S2Setmana
2

🟡 Adaptació i optimització

Implementar els controls FPS complets, comprimir textures i fer el bake de llums de l'escena. Integrar la lògica d'enviament de puntuació al joc.

  • Controls WASD + Pointer Lock API
  • Compressió de textures (BC7 → ASTC/ETC2 per WebGL)
  • Bake de llums estàtiques amb Lightmass
  • Plugin VaRest per enviar JSON al backend
S3Setmana
3

🟢 Integració i llançament

Disseny final de la web, base de dades MySQL operativa i tests de càrrega amb múltiples jugadors simultanis.

  • Disseny responsive complet HTML/CSS
  • API PHP per a puntuacions (add, remove, reset)
  • Tests de concurrència (≥10 jugadors alhora)
  • Deploy al servidor i configuració CORS

03 — Avisos importants

Limitacions & Riscos

⚠️
Plugin no oficial: L'exportació HTML5 de UE5 depèn d'un plugin comunitari. Pot tenir bugs i no estar actualitzat a la versió 5.5.4.
💡
Requisits de l'usuari: El navegador necessita suport WebGL 2.0 i un mínim de 4 GB de RAM lliure per executar el joc fluidament.
📦
Mida del joc: Un projecte UE5 optimitzat per web pot pesar 150–500 MB. Considera usar un CDN per a la distribució dels assets.
ℹ️
Pla B: Si UE5 → WebGL falla, Unity WebGL i Godot 4 (HTML5) ofereixen exportació nativa estable i gratuïta.
